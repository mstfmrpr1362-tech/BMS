# سامانه مدیریت دارایی پل‌های سواره‌رو تهران (BMS)

این مخزن، طرح اولیه سامانه مدیریت دارایی و اولویت‌بندی ۸۸۰ پل سواره‌رو شهرداری تهران را نگهداری می‌کند. تمرکز نسخه فعلی روی تعریف مدل داده، فرایند بازدید مناطق، فرم‌های بازدید میدانی، ثبت عکس خرابی‌ها و الگوریتم اولویت‌بندی نگهداشت است.

## مستندات

- [طرح محصول و فرم‌های بازدید بر اساس سند 6-8-620](docs/bridge-bms-design-fa.md)
- [JSON Schema فرم بازدید پل](schemas/inspection-form.schema.json)

## دامنه نسخه اول

1. نمایش ۸۸۰ پل روی نقشه بر اساس مختصات، منطقه و ناحیه.
2. ثبت شناسنامه دارایی برای هر پل شامل نوع سازه، سیستم عرشه، پایه، کوله، تکیه‌گاه و تجهیزات ایمنی.
3. اجرای بازدید ادواری توسط مناطق با فرم استاندارد و الزام پیوست عکس برای هر خرابی.
4. محاسبه امتیاز وضعیت، ریسک و اولویت مداخله برای برنامه‌ریزی تعمیرات.
